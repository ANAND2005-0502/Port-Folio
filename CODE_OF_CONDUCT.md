# Code of Conduct

## Our Pledge

We welcome contributors of all backgrounds and experience levels. Everyone who
participates in this project is expected to be respectful, kind, and constructive.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect different viewpoints and experiences.
- Give and receive feedback gracefully.
- Focus on what is best for the project and its contributors.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Repeated disruption of project discussions.

## Enforcement

Project maintainers may remove comments, close issues, or block contributors who
do not follow this Code of Conduct.
