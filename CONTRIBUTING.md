# Contributing

Thank you for helping improve this portfolio.

## How to Contribute

1. Fork the repository.
2. Create a branch: `git checkout -b fix/small-improvement`.
3. Make a focused change.
4. Test the page by opening `index.html` in a browser.
5. Commit with a clear message.
6. Open a pull request and describe what changed.

## Good First Contributions

- Fix typos.
- Improve accessibility labels.
- Add project links.
- Improve responsive styling.
- Update documentation.

## Pull Request Checklist

- The page still loads in a browser.
- Links are correct.
- Text is readable on mobile and desktop.
- The change is small and easy to review.
