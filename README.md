# Anand Mishra Portfolio

A bare minimum portfolio for open-source contribution. It highlights projects,
skills, contribution interests, and contact links.

## Tech Stack

- HTML
- CSS
- GitHub Actions

## Run Locally

Open `index.html` in a browser.

## Customize

- Update project links in `index.html`.
- Replace the LinkedIn placeholder with your real profile URL.
- Edit the contribution interests in the Open Source Contributions section.
